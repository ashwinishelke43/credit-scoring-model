# Credit Scoring Model

## Project Overview
This project predicts whether a loan applicant is eligible for credit approval using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression

## Features
- Income analysis
- Loan amount analysis
- Credit score analysis
- Loan approval prediction

## How It Works
1. Load the dataset.
2. Split data into training and testing sets.
3. Train a Logistic Regression model.
4. Predict loan approval.
5. Display model accuracy.
